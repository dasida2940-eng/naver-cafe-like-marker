# 네이버 카페 좋아요 표시

네이버 카페 글 목록에서 내가 좋아요를 누른 글을 분홍 배경과 ♥ 표시로 알려 주는 크롬 확장 프로그램입니다.

- [Chrome 웹 스토어에서 설치](https://chromewebstore.google.com/detail/nmfcdiflgghgkbjdlpnjmndgajjjmfco)
- [개인정보처리방침](privacy)
- [문의·오류 제보 (GitHub Issues)](https://github.com/dasida2940-eng/naver-cafe-like-marker/issues)
- [소스 코드 (GitHub)](https://github.com/dasida2940-eng/naver-cafe-like-marker)

## 주요 기능

- 좋아요 누른 글을 목록에서 배경색·하트로 표시
- 표시 방식 선택: 배경만 / 배경+하트 / 하트만
- 다음글·이전글 버튼에도 표시
- 카페의 "좋아요한 글" 목록에서 기존 좋아요 기록 가져오기

모든 기록은 사용자의 브라우저 안(chrome.storage.local)에만 저장되며 외부로 전송되지 않습니다.
