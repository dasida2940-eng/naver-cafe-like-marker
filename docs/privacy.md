# 네이버 카페 좋아요 표시 – 개인정보처리방침

최종 수정일: 2026년 11월 8일 (v1.9.0)

## 1. 처리하는 정보
- 사용자가 좋아요를 누른 네이버 카페 게시글의 카페 번호, 카페 이름, 글 번호, 저장 시각
- 표시 방식 설정 (배경 / 하트)

## 2. 이용 목적
게시판 목록에서 사용자가 좋아요한 글을 표시하는 기능에만 사용합니다.

## 3. 저장 위치 및 전송
모든 정보는 사용자의 브라우저(`chrome.storage.local`)에만 저장됩니다. 개발자를 포함한 외부 서버나 제3자에게 전송, 공유, 판매하지 않습니다.

## 4. 좋아요한 글 목록 읽기
사용자가 네이버 카페의 "나의 활동 → 좋아요한 글" 화면에서 가져오기 버튼을 누르면, 확장 프로그램이 그 화면에 표시된 글 목록(카페 번호, 글 번호)을 읽어 위 1번 정보로 저장합니다. 버튼을 누르지 않으면 읽지 않습니다. 목록이 여러 페이지면 사용자의 브라우저 안에서 페이지 버튼을 차례로 눌러 읽습니다. 읽은 정보는 외부로 전송되지 않습니다.

## 5. 보관 및 삭제
확장 프로그램을 삭제하면 저장된 정보도 함께 삭제됩니다. 게시글에서 좋아요를 취소하면 해당 기록이 삭제됩니다.
