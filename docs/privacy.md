# 네이버 카페 좋아요 표시 – 개인정보처리방침

최종 수정일: 2026년 11월 4일

## 1. 처리하는 정보
- 사용자가 좋아요를 누른 네이버 카페 게시글의 카페 번호, 카페 이름, 글 번호, 저장 시각
- 표시 방식 설정 (배경 / 하트)

## 2. 이용 목적
게시판 목록에서 사용자가 좋아요한 글을 표시하는 기능에만 사용합니다.

## 3. 저장 위치 및 전송
모든 정보는 사용자의 브라우저(`chrome.storage.local`)에만 저장됩니다. 개발자를 포함한 외부 서버나 제3자에게 전송, 공유, 판매하지 않습니다.

## 4. 보관 및 삭제
확장 프로그램을 삭제하면 저장된 정보도 함께 삭제됩니다. 게시글에서 좋아요를 취소하면 해당 기록이 삭제됩니다.

## 5. 문의
이 프로젝트 GitHub 저장소의 Issues 탭으로 문의해 주세요.
